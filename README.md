# Smart Financial Services Kiosk with AI Advisory System

A web-based personal financial management kiosk integrating AI-powered advisory, secure KYC document handling, and fraud detection.

## Project Overview
This project presents an interactive, web-based financial services kiosk powered by artificial intelligence[span_0](start_span)[span_0](end_span)[span_1](start_span)[span_1](end_span). Developed using Python, Flask, and SQLite, the platform provides users with an intuitive dashboard to track personal finances, access personalized AI advisory via the Groq API, interact with a financial chatbot, verify suspicious transactions to prevent fraud, and securely upload and manage KYC documents[span_2](start_span)[span_2](end_span)[span_3](start_span)[span_3](end_span)[span_4](start_span)[span_4](end_span)[span_5](start_span)[span_5](end_span).
